# Feuille de route TaskMiner

TaskMiner est un SaaS de gestion collaborative de projets conçu autour d'une API
FastAPI, de PostgreSQL et d'un frontend React. Le produit couvre aujourd'hui son
périmètre fonctionnel principal et entre dans une phase de stabilisation.

## Statuts

- ✅ Terminé
- 🚧 En cours
- ⏳ À faire

- [x] ✅ Sprints 1–4 — Fondations backend, Docker, données et architecture API
- [x] ✅ Sprints 5–7 — Authentification, projets, tâches et tests backend
- [x] ✅ Sprints 8–11 — Recherche, soft delete, pièces jointes et CI
- [x] ✅ Sprints 12–17 — Commentaires, assignation, workspaces, rôles et invitations
- [x] ✅ Sprints 18–19 — Domain Events, Activity Feed et Audit Log
- [x] ✅ Sprints 20–22 — Fondations frontend, authentification et CRUD connectés
- [x] ✅ Sprints 23–26 — Dashboard, Kanban et invitations frontend
- [x] ✅ Sprints 27–30 — Temps réel, analytics avancées et Settings
- [x] ✅ Sprint 31 — Product Polish, accessibilité, responsive et branding
